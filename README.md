# Vrinda Store Data Analysis – 2022

## Project Overview
This project analyzes Vrinda Store's 2022 sales data using Microsoft Excel to identify sales trends, customer behavior, order performance, and high-performing sales channels.

## Objectives
- Analyze monthly sales and order trends.
- Compare purchasing patterns by gender and age group.
- Evaluate order statuses, including delivered, cancelled, returned, and refunded orders.
- Identify the top-performing states.
- Analyze sales distribution across e-commerce channels.

## Tools & Techniques
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Data Analysis and Visualization
- Excel formulas for data categorization

## Key Analysis Areas
1. **Sales vs. Orders:** Monthly comparison of sales amounts and order counts.
2. **Gender Analysis:** Comparison of sales by men and women.
3. **Order Status:** Analysis of delivered, cancelled, returned, and refunded orders.
4. **Geographical Analysis:** Identification of the top five states by sales amount.
5. **Age and Gender Analysis:** Customer segmentation by age group and gender.
6. **Sales Channels:** Comparison of orders across online shopping platforms.

## Project Files
- `Data Analyst Project Excel.xlsx` – Excel workbook containing the source data, analysis sheets, and annual report.

## Key Learnings
- Practiced analyzing large datasets in Excel.
- Explored customer segmentation and sales trends.
- Used structured summaries to support data-driven business insights.
- Improved skills in Excel-based reporting and data visualization.

## Conclusion
This project demonstrates how Excel can transform raw retail sales data into meaningful information that supports business reporting and decision-making.
